## 2. 카테고리별 공식 사용 순서 (S1 원문)

- 쇼핑몰 바로사용: ① 메인화면에서 [바로사용] 메뉴 클릭 ② 쇼핑몰 선택 ③ [컬쳐캐쉬 사용하기] 클릭 ④ 제휴사 내 구매 상품 결제창에서 '컬쳐랜드 컬쳐캐쉬' 선택 ⑤ 컬쳐랜드 계정으로 로그인 ⑥ 컬쳐캐쉬 사용 후 결제
- 구글플레이 기프트 코드 구매: ① 안드로이드 App / 모바일웹에서 [구글플레이 기프트코드] 메뉴 클릭 ② 구매할 권종 선택 ③ 수신번호 및 결제수단 선택 ④ 수신자 정보 확인 ⑤ 구매 완료
- 오프라인 바코드 결제: ① 컬쳐랜드상품권(모바일문화상품권) 잔액과 결제 가능 사용처 확인 ② 상품권(MMS/바코드)을 제시하여 결제. 유의: "잔액 관리형 상품권으로 남은 금액 자유롭게 사용 가능"
- 모바일 쿠폰 구매: ① 메인화면에서 [쿠폰] 메뉴 클릭 ② 구매할 권종 선택 ③ 수신번호 및 결제수단 선택 ④ 수신자 정보 확인 ⑤ 구매 완료 (S1 사용방법 팝업, 2026-11-08 Aside로 확인)
- 포인트 전환: ① 메인화면에서 [캐쉬 전환] 메뉴 클릭 ② 전환 제휴사 선택 ③ 최초 1회 정보제공동의 ④ 전환 금액 입력 ⑤ 전환 완료

## 4. "사용 불가 / 결과 없음" 데모 예시

- **올리브영 오프라인 매장 바코드 결제**: S1에서 올리브영은 "모바일 쿠폰 구매"에만 있고, "오프라인 바코드 결제" 목록에는 없음 → 화면 문구 예: "올리브영은 모바일 쿠폰 구매로만 이용 가능 (매장 바코드 결제 목록에 없음)". 바로 결제가 안 된다는 확정 문구 대신 "공식 목록 미기재"로 표기 권장.
- **스타벅스 매장 바코드 결제**: 같은 경우 (모바일 쿠폰 구매에만 기재).
- 목록에 없는 검색어 (예: 넥슨): S1 미기재 → "공식 사용처 목록에서 찾을 수 없음 — 고객센터 1577-2111 확인" 처리. 사용 불가로 단정하지 말 것 (미확인).
