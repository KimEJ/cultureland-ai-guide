# 컬쳐랜드상품권 / 컬쳐캐쉬 사용 방법 팩트베이스 (데모 범위)

확인일: 2026-11-08. 공식 출처(cultureland.co.kr)만 사용. 공식 출처에서 확인하지 못한 항목은 [미확인]으로 표시.

## 0. 기본 개념
- 컬쳐캐쉬: "컬쳐랜드와 다양한 온·오프라인 제휴처에서 현금처럼 사용할 수 있는 통합 결제 수단" [출처: https://www.cultureland.co.kr/guide/culturecashGuide.do, 확인일 2026-11-08]
- 컬쳐랜드상품권 = "모바일문화상품권의 새 이름", "잔액 관리형 상품권" [출처: https://www.cultureland.co.kr/voucher/mobile.do, 확인일 2026-11-08]
- 컬쳐캐쉬로 충전 가능: (주)한국문화진흥 발행 컬쳐랜드상품권(모바일문화상품권). 지류/온라인문화상품권은 충전 불가 [출처: https://www.cultureland.co.kr/customer/customerMain.do (FAQ), 확인일 2026-11-08]
- PIN 자릿수 [미확인: 공식 페이지에 명시 없음]

## 1. 상품권 PIN → 컬쳐캐쉬 충전
- 방법 A (바로충전): 상품권 잔액/사용처 확인 → 바로충전 URL 클릭 → 컬쳐랜드 ID/비밀번호 입력 → 충전 완료 [출처: https://www.cultureland.co.kr/voucher/mobile.do, 확인일 2026-11-08]
- 방법 B (직접 입력): Web/App 로그인 → 충전 > 컬쳐랜드상품권(모바일문화상품권) → 상품권 번호 입력 [출처: 같은 페이지, 확인일 2026-11-08]
- 충전 메뉴 URL: 웹 https://www.cultureland.co.kr/charge/gift/getCulVoucher.do / 모바일 https://m.cultureland.co.kr/csh/cshGiftCard.do (로그인 필요) [출처: 각 URL, 확인일 2026-11-08]
- 보유한도: 보유한도를 넘는 금액은 '대기 컬쳐캐쉬'로 충전·적립되며, 잔액이 차감되면 그만큼 사용 가능 컬쳐캐쉬로 자동 전환됨 [출처: https://www.cultureland.co.kr/usecash/getCashHow.do, 확인일 2026-11-08]
- 컬쳐캐쉬를 50만원 이상 보유하려 하면 고객확인제도(CDD/EDD)를 이행해야 함. 마이페이지 '보유 한도 늘리기'에서 신청 [출처: https://www.cultureland.co.kr/customer/customerMain.do (FAQ), 확인일 2026-11-08]
- 일/월 충전 한도 금액 [미확인]
- 상품권 충전 수수료 [미확인: 공식 FAQ에 언급된 수수료는 환불 관련뿐]

## 2. 오프라인 바코드 결제
- 오프라인: 상품권(MMS 또는 바코드)을 제시해 결제, 남은 잔액은 이후 사용 가능. 사용처는 전국 편의점(CU, GS25, 세븐일레븐, 이마트24), 교보문고, CGV 등 [출처: https://www.cultureland.co.kr/voucher/mobile.do, 확인일 2026-11-08]
- 컬쳐캐쉬 바코드 결제 브랜드 목록 메뉴 존재: https://m.cultureland.co.kr/tgl/barcodeBrandList.do (로그인 필요, 내용 미확인)
- 앱 컬쳐캐쉬 바코드 결제 단계별 절차 [미확인]

## 3. 온라인 결제 (제휴 쇼핑몰 결제창에서 컬쳐캐쉬 선택, "바로사용")
1. 컬쳐캐쉬를 쓸 쇼핑몰로 이동
2. 상품 결제 단계에서 결제 수단으로 컬쳐캐쉬 선택
3. 컬쳐캐쉬 잔액 확인 후 결제 완료
- 결제창에서 컬쳐랜드 로그인 [출처: https://www.cultureland.co.kr/voucher/mobile.do, 확인일 2026-11-08]
- 유의: 안심금고에 보관 중인 금액이 아닌 '사용 가능' 컬쳐캐쉬인지 확인. 브랜드별 정책은 각 화면 하단 유의사항 참고 [출처: https://www.cultureland.co.kr/usecash/getCashHow.do, 확인일 2026-11-08]

## 4. 전환 (예: 네이버페이 포인트)
1. 전환할 제휴 포인트 선택
2. 금액 입력 후 '전환하기' 클릭
3. 컬쳐캐쉬 총 결제 금액 확인
4. 전환 완료
- 컬쳐랜드 본인인증 회원만 이용 가능. 제휴사 아이디와 컬쳐랜드 아이디의 명의자가 같아야 함 [출처: https://www.cultureland.co.kr/usecash/getCashHow.do, 확인일 2026-11-08]
- 휴대폰 본인인증 회원만 가능. 간편인증 회원은 마이페이지 > 개인정보관리 > 회원전환 [출처: https://www.cultureland.co.kr/customer/customerMain.do (FAQ), 확인일 2026-11-08]
- 전환 제휴처(메뉴 기준): 쿠팡캐시, Google Play 기프트 코드, 네이버페이 포인트, GLN G앱머니, PAYCO 포인트, SSG MONEY, 스마일머니, 해피포인트, 11pay 포인트, L.POINT, 아파트캐시 등 [출처: https://m.cultureland.co.kr/convs/convsMain.do, 확인일 2026-11-08]
- Npay 전환: 적립 포인트로 전환되므로 현금영수증 발행 불가. 개인정보 제3자 제공에 동의하지 않으면 이용 불가 [출처: https://m.cultureland.co.kr/convs/convsApp.do?company=npay3, 확인일 2026-11-08]
- 네이버페이 전환 수수료, 일/월 한도 [미확인: 공식 페이지에서 확인 못함. 제3자 블로그에 "수수료 6%, 일 10만/월 200만"이 있으나 비공식이므로 사용 금지]
